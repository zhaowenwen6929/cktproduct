# 团队积分统计

> 对应独立需求说明：[docs/积分统计-需求说明.md](../../../docs/积分统计-需求说明.md)。

## 页面目标

在「管理 > 积分统计」中还原原型的四个统计模块：积分概览、今日使用、消耗趋势、消耗榜单。积分概览和今日使用为实时数据，消耗趋势和消耗榜单为 T+1 数据。使用统计与积分统计保持同级，但使用统计暂未放置内容。

## 功能清单

| 模块 | 原型要求 |
| --- | --- |
| 页面入口 | 与账户概览、使用统计同级；权限和会员版本限制与使用统计一致。 |
| 积分概览 | 剩余积分、本月已消耗、今日已消耗；升级会员/增购显示规则；变化率 hover 详情。 |
| 今日使用 | 最近 24 小时最新消耗，最多 5000 条；成员消耗统计及查看全部。 |
| 消耗趋势 | T+1；过去7天/30天/上周/上月、自定义日期、天/周/月；消耗积分/成员/功能三种维度；hover 分析；导出。 |
| 消耗榜单 | T+1；与趋势时间范围一致；成员 Top10 与功能 Top10，展示名称、占比、积分。 |
| 需求说明 | 页面右上角独立悬浮入口；需求描述和重点批注不进入导出数据。 |

## 关键规则

1. 剩余积分为当前团队账户剩余积分；团队等级小于 302 显示「升级会员领更多积分」，点击打开会员版本选择弹框；达到 302 及以上只显示「增购」，且增购显示为大按钮。
2. 本月已消耗和今日已消耗包含功能消耗及到期自动失效；变化率分别与上月、昨日比较，按公式计算并保留 2 位小数，上月/昨日为 0 时显示「-」。
3. 最新消耗实时获取最近 24 小时明细，最多 5000 条；查看全部跳转至「积分管理 > 积分明细 > 消耗明细」。
4. 消耗趋势的最晚日期为昨日，最早日期为积分上线时间，最长跨度 90 天；默认过去 7 天、按天、消耗积分。
5. 消耗积分趋势展示总消耗、功能消耗、到期失效；成员/功能趋势展示对应总量及分析信息。
6. 榜单按当前时间范围及粒度从高到低取 Top10；占比为当前对象积分数除以该维度全部对象积分数。
7. 需求说明属于功能外文档，趋势导出只包含当前趋势数据。

## 示例数据

- 剩余团队积分数：`89373737`
- 本月已消耗：`7723`，较上月 `+12%`
- 今日已消耗：`773`，较昨日 `+12%`
- 成员消耗示例：张美丽、成员、最近24小时、200积分、50次
- 趋势示例日期：1月28日—2月3日；hover 示例日期：2026年2月3日

## 页面状态

- 加载中：指标、今日使用、趋势、榜单显示加载中。
- 空数据：显示「暂无积分消耗数据」并保留筛选操作。
- 加载失败：显示「积分统计加载失败，请重试」并提供重试。
- 无权限：显示权限说明，不展示其他团队数据。
- 导出中/失败：阻止重复提交并反馈明确结果。

## 验收重点

- 页面包含四个模块，且使用统计与积分统计同级。
- 积分概览的会员等级判断、增购按钮、变化率颜色和 hover 文案正确。
- 今日使用的实时 24 小时明细、5000 条上限、成员统计和跳转文案正确。
- 趋势筛选、三类数据线、hover 分析、导出和日期边界符合原型。
- 成员榜单与功能榜单各显示 Top10、名称、占比和积分。
- 需求说明独立于导出数据。
