# 团队积分统计

> 对应独立需求说明：[docs/积分统计-需求说明.md](../../../docs/积分统计-需求说明.md)。

## 页面类型

后台列表类 / 统计报表类 / 用户中心类。

## 页面目标

在团队管理 > 使用统计中，展示当前团队积分余额、周期消耗、新增积分、每日消耗趋势及可筛选的积分消耗明细。页面必须区分原型示例数据与正式接口数据，并覆盖空数据、失败和无权限状态。

## 功能清单

| 模块 | 功能 |
| --- | --- |
| 页面入口 | 管理 > 使用统计；管理员可见，普通成员无权限。 |
| 指标概览 | 当前剩余、本月消耗、本月新增、今日消耗。 |
| 筛选 | 使用类型、时间范围、成员/功能关键词。 |
| 趋势图 | 按日聚合所选范围内的积分消耗。 |
| 明细表 | 时间、成员、功能、类型、消耗积分、消耗后余额。 |
| 导出 | 携带当前筛选条件导出明细；格式及条数待后端确认。 |
| 需求说明 | 页面内打开结构化说明并支持复制 AI 提示词。 |

## 业务规则

1. 所有数据限定当前团队，不跨团队聚合。
2. 趋势、指标和明细使用相同的团队、时区和积分账本口径。
3. 默认时间范围为近30天，明细默认按消耗时间倒序、每页10条。
4. 筛选变化后趋势和列表同步刷新，列表回到第一页。
5. 无权限、空数据、加载失败和导出失败均需提供明确状态与下一步操作。

## 验收重点

- 页面标题和侧边栏入口正确。
- 四项指标、趋势图和明细表展示口径一致。
- 时间、类型和成员筛选可组合使用。
- 空态、失败态、无权限态和导出反馈可验证。
- 页面需求说明包含背景、目标、功能、交互、接口、权限和验收标准。
