# 积分分配与管理

> 对应独立需求说明：[docs/积分管理-需求说明.md](../../../docs/积分管理-需求说明.md)。

## 页面路径

`创客贴管理后台 > 团队管理 > 积分管理`

## 页面目标

提供团队积分的分配、成员额度管理和积分明细查询。页面与「积分统计」「使用统计」同级，默认进入「配额管理」，并通过点击串联所有原型中的弹框和页面入口。

## 功能清单

| 模块 | 原型要求 |
| --- | --- |
| 分配模式 | 共享池模式/配额模式，默认共享池；支持模式切换及切换提示。 |
| 成员配额 | 角色筛选、名称/邮箱搜索、消耗进度、限额、状态和操作。 |
| 成员操作 | 编辑限额、临时加量、暂停、恢复、重置；全部通过点击打开对应弹框。 |
| 通用策略 | 创建者、管理员、设计师、成员的额度、透支和无限配置。 |
| 积分明细 | 充值/奖励与消耗明细，支持月份、来源、成员、功能筛选。 |
| 功能入口 | 按分配模式显示团队或成员实际可用积分，统一文案为团队可用积分。 |
| 需求说明 | 页面右上角独立入口；正文不进入业务导出。 |

## 关键验收

1. 入口与页面标题为「积分管理」「积分分配与管理」，默认 Tab 为「配额管理」。
2. 账户概览和积分统计的相关入口可以定位到积分明细的消耗明细 Tab。
3. 所有弹框均有关闭、取消、保存或确认操作，状态更新后反馈明确。
4. 成员消耗进度、状态颜色、无限限额和操作置灰逻辑符合需求说明。
5. 积分明细两个子 Tab 和各自筛选条件能正常切换。
6. 需求说明悬浮按钮打开完整说明，说明内容和业务导出保持独立。
