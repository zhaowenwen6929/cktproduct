# 积分管理｜需求说明

## 1. 页面范围与入口

- 「积分管理」与「账户概览」「使用统计」「积分统计」保持同一级别。
- 团队创建者和管理员可见并可操作；所有团队版会员可见，非团队会员显示「升级团队版会员，立即使用」入口。
- 进入路径：`管理 > 积分管理`，页面标题为「积分分配与管理」。
- 页面顶部提供「配额管理」「积分明细」两个 Tab，默认打开「配额管理」。
- 右上角独立提供「需求说明」悬浮按钮。需求说明属于功能外的产品文档，不加入积分明细或任何业务导出数据。

## 2. 配额管理

### 2.1 分配模式

提供「共享池模式」和「配额模式」两个单选项，默认选中「共享池模式」。

- 共享池模式：所有团队成员均消耗共享团队积分池；功能入口显示团队剩余积分。
- 配额模式：每个成员按照自己的月度最大消耗额度消耗；功能入口显示当前成员实际可用剩余量。
- 两种模式在团队会员有效期内可以随意切换，切换时保留之前的设置。
- 团队会员过期后自动切换为共享池模式。
- 首次切换到配额模式时，先弹出「团队通用配额策略」配置框。
- 从共享池切换为配额模式时提示：所有成员将按照设置的最大配额进行消耗；已达到或超过最大限额的成员无法继续使用消耗积分的功能，进行中的消耗任务会立即中断；新加入成员默认使用对应角色的配额配置。
- 从配额模式切换为共享池模式时提示：所有团队成员均消耗团队积分池；当前模式下对成员/团队角色限额的编辑、加量、重置操作仅保留修改，不生效。
- 模式切换前需要用户输入「已确认并切换为配额模式」或「已确认并切换为共享池模式」后，才允许确认切换。

### 2.2 成员配额列表

成员配额区域展示「团队通用配额策略」入口、角色筛选、成员名称/邮箱搜索及成员列表。

表格字段为：`名称｜角色｜本月消耗｜当前限额｜状态｜操作`。

- 成员列表按加入团队的顺序展示，与成员列表的成员信息和角色保持一致。
- 本月消耗按「本月已消耗 / 当前限额」展示进度条，hover 进度条显示比例。
- 当前限额为「无限」时只显示灰色进度条，不显示比例。
- 本月消耗小于当前限额的 80%：状态为「正常」，绿色。
- 本月消耗大于等于 80% 且小于 100%：状态为「警告」，橙色。
- 本月消耗大于等于 100%：状态为「已耗尽」，红色。
- 暂停成员消耗后：状态为「已暂停」，操作入口变为「恢复」。
- 共享池模式下当前限额均为「无限」；进度条和可用积分口径使用团队共享积分池。

原型示例：

| 名称 | 角色 | 本月消耗 | 当前限额 | 状态 |
| --- | --- | ---: | ---: | --- |
| 张美丽 | 创建者 | 2500 | 3000 | 正常（60%） |
| 王小四 | 管理员 | 3000 | 3000 | 已耗尽 |
| 李小宝 | 设计师 | 2500 | 2800 | 警告 |
| 李小宝 | 成员 | 2500 | 无限 | 正常 |

## 3. 成员操作弹框

### 3.1 编辑限额

点击成员「编辑」或当前限额旁的编辑图标，打开「编辑限额」弹框。

- 展示「成员信息」、头像/名称和角色标签。
- 分配模式提供「跟随团队策略」「自定义独立额度」，默认跟随团队策略。
- 跟随团队策略：成员使用团队通用配额策略中对应角色的配置；已配置时显示对应角色的额度。
- 自定义独立额度：展示「设置周期额度上限」「积分/月」「允许透支」「允许透支比例」「设为无上限」。
- 数值只能输入非负整数，不允许小数和负数；最小值不能低于当前周期已使用值。
- 「设为无上限」勾选后清空并禁用额度输入，当前限额展示为「无限」。
- 「允许透支」可配置 0—100% 的透支比例；无限时透支比例不生效。
- 点击「取消」或关闭图标不保存；点击「保存」校验通过后保存并更新列表。

### 3.2 成员临时加量

点击「加量」打开「成员临时加量」弹框。

- 文案为「一次性增加积分上限，仅本月有效」。
- 输入增加的积分数，单位为「积分」；也可勾选「设为无上限」。
- 成功后只增加当月可用上限，次月不再生效。
- 当前成员已为无限限额时，「加量」入口置灰不可操作。
- 成功通知：`增加可用积分`，说明本次增加的积分数和有效期；下月 1 日自动失效。

### 3.3 暂停与恢复成员消耗

- 点击「暂停」弹出「暂停成员消耗」确认框；确认后中断正在运行的积分消耗任务，拒绝新的消耗请求，状态变为「已暂停」。
- 暂停成功通知标题为「暂停积分消耗」，说明团队管理员已暂停该成员的积分消耗，相关任务也会暂停。
- 已暂停成员点击「恢复」弹出「恢复成员消耗」确认框；确认后恢复成员消耗资格，已中断的任务不能自动恢复，需要成员手动恢复。
- 恢复成功通知标题为「恢复积分消耗」，说明成员需要手动恢复中断任务。
- 取消或关闭确认框不改变成员状态。

### 3.4 重置成员消耗

点击「重置」弹出「重置成员消耗」确认框。

- 将成员当前周期的展示消耗量重置为 0，恢复本周期可用额度。
- 不删除真实消耗日志；所有 Token 消耗仍保留并计入真实成本。
- 重置后，成员列表的本月消耗进度重新计算，成员真实历史仍可在积分明细中查询。
- 重置成功通知管理员并记录审计日志：`管理员 Admin 于 [时间] 重置了 [用户] 的本月累积消耗`。

### 3.5 团队通用配额策略

点击「团队通用配额策略」打开策略配置弹框，默认打开「成员分配策略」。

- 角色范围：创建者、管理员、设计师、成员。
- 每个角色可独立启用/停用并展开设置；新成员加入后默认使用对应角色配置。
- 每个角色配置「设置周期额度上限」「积分/月」「允许透支」「最多透支比例」「设为无上限」。
- 未启用角色配置，或角色配置为空时，该角色的通用配额不生效。
- 保存前需提示「未启用角色配置 或 角色下配置为空时，通用配额将不生效，请检查并核对后再保存」。
- 「暂不设置」取消保存并关闭；「返回设置团队通用配额」返回策略表单；配置完整后点击「保存」生效。
- 付费团队实际购买成员数大于 10 人时，显示对应的策略配置提示。

## 4. 积分明细

「积分明细」Tab 下分为「充值/奖励」和「消耗明细」。

### 4.1 充值/奖励

- 展示「月度累计 8392积分」。
- 筛选项：月份（默认 `2026年1月`）和来源（默认「选择来源」）。
- 表格字段：`来源｜时间｜金额变化`。
- 原型示例：`平台赠送｜2026-1-10 13:18:09｜+1000`。
- 来源筛选仅显示当前月份产生积分的来源记录。

### 4.2 消耗明细

- 展示「月度消耗 8392积分」。
- 筛选项：月份（默认 `2026年1月`）、成员（默认「所有成员」）、功能（默认「所有功能」）。
- 表格字段：`时间｜成员｜功能｜消耗积分`。
- 原型示例：`2026年1月2号13:18:09｜赵文文｜AI创作/无限画布/AI变清晰/AI生图｜-100`。
- 点击统计页「查看全部」直接进入「积分管理 > 积分明细 > 消耗明细」。

## 5. 功能入口显示可用积分

- 共享池模式下：使用团队剩余积分，功能入口显示团队可用积分。
- 配额模式下：使用当前成员实际可用剩余量；如果成员设置为无限，则显示团队剩余积分；其他情况显示成员配额剩余量。
- 功能入口文案统一显示为「团队可用积分」。
- 非团队会员时，功能入口展示升级团队版会员入口；升级后按照所选分配模式显示可用积分。

## 6. 需求说明与导出边界

- 页面右上角「需求说明」打开本说明的侧边栏/全屏文档，保持橙色需求正文、紫色重点提示和原型中的重点文案层级。
- 需求说明需要覆盖页面入口、分配模式、成员配额、编辑限额、临时加量、暂停、恢复、重置、通用策略、积分明细、功能入口等模块。
- 红色箭头、红框、截图批注只用于说明定位，不进入产品页面，不进入导出内容。
- 任何积分明细或趋势导出均只导出业务数据，不导出需求说明、重点说明、批注和截图。

## 7. 验收标准

- [ ] 从「管理」进入「积分管理」，页面标题、Tab、分配模式、成员配额和积分明细与原型一致。
- [ ] 「积分统计」的查看全部、账户概览的查看明细均能进入「积分管理 > 积分明细 > 消耗明细」。
- [ ] 「增购」能直接打开积分购买弹框；编辑、加量、策略、暂停、恢复、重置均通过点击触发对应弹框。
- [ ] 所有取消、关闭、保存和二次确认行为可用，弹框之间不互相遮挡，列表不被常驻浮层遮挡。
- [ ] 成员进度比例、正常/警告/已耗尽/已暂停状态和无限限额表现符合规则。
- [ ] 积分明细的充值/奖励、消耗明细切换，以及月份、来源、成员、功能筛选可用。
- [ ] 需求说明按钮独立于业务导出，导出数据不包含需求说明和截图批注。
