# 积分统计｜需求说明

参考原型：<https://axhub.im/ax11/b7d9e872448cdd88/?id=4kjy4j&p=%E7%A7%AF%E5%88%86%E7%BB%9F%E8%AE%A1&g=1&sc=3>

## 1. 页面范围

- 积分统计与使用统计保持同一级别，权限和会员版本限制保持一致。
- 使用统计暂未放置内容；积分统计页面包含「积分概览」「今日使用」「消耗趋势」「消耗榜单」4 部分统计。
- 「积分概览」「今日使用」为实时数据，截止到当前的最近数据。
- 「消耗趋势」「消耗榜单」为 T+1 统计数据。
- 页面右上角提供独立的「需求说明」悬浮按钮。需求说明属于功能之外的产品说明，不写入导出数据。

## 2. 页面入口与导航

```text
团队管理
├── 账户概览
├── 使用统计（暂未放置内容）
└── 积分统计
    ├── 积分概览
    ├── 今日使用
    ├── 消耗趋势
    └── 消耗榜单
```

入口为「管理 > 积分统计」，点击后页面标题为「积分概览」。左侧「积分统计」与「账户概览」「使用统计」同级显示并高亮；点击「使用统计」只保留入口并提示功能即将上线。

## 3. 积分概览

### 3.1 实时口径

积分概览展示当前团队截至当前时间的最近数据，示例团队为「北京艺源酷」。

### 3.2 剩余积分

- 数值：当前团队账户剩余的积分数。
- 升级会员按钮：当前团队等级小于 302 时显示「升级会员领更多积分」，点击打开会员版本选择弹框；团队等级达到 302 及以上时不显示该按钮，只显示「增购」入口。
- 增购：一直显示。当没有升级会员按钮时，增购显示为大按钮；点击打开积分购买弹框。
- 原型示例数值：`89373737`。

### 3.3 本月已消耗积分

- 数值：当前团队本月已消耗的积分总和，包括功能消耗和到期自动失效。
- 较上月：展示较上月的变化率，hover 时展示详情。
- 计算公式：`（本月消耗值 - 上月消耗值）/ 上月消耗值`。
- 展示规则：保留 2 位小数；正数为绿色，负数为红色，0 按常规黑色；上月为 0 时显示「-」。
- hover 文案格式：`本月消耗 mm 较上月消耗 xx 增长 yy%`。
- 原型示例数值：`7723`、`较上月 +12%`。

### 3.4 今日已消耗积分

- 数值：当前团队今日已消耗的积分总和，包括功能消耗和到期自动失效。
- 较昨日：展示较昨日的变化率，hover 时展示详情。
- 计算公式：`（今日消耗值 - 昨日消耗值）/ 昨日消耗值`。
- 展示规则：保留 2 位小数；正数为绿色，负数为红色，0 按常规黑色；昨日为 0 时显示「-」。
- hover 文案格式：`今日消耗 mm 较昨日消耗 xx 增长 yy%`。
- 原型示例数值：`773`、`较昨日 +12%`。

## 4. 今日使用

### 4.1 最新消耗

- 实时获取当前团队最近 24 小时内的所有消耗明细。
- 最多显示 5000 条。
- 每条记录展示：时间、成员、使用功能、消耗积分。
- 原型示例文案：
  - `5分钟前｜张三｜使用 无限画布 生图｜消耗 5积分`
  - `今天 14:10:56｜小强｜使用 无限画布 生设计｜消耗 10积分`
  - `今天 10:30:20｜李四｜使用 无限画布 生视频｜消耗 100积分`
  - `昨天 20:18:10｜王五｜使用 AI文案 生文本｜消耗 10积分`
  - `昨天 20:18:10｜系统｜到期自动失效｜消耗 1000积分`
- 点击某个成员，弹框展示该成员当前团队最近 24 小时的消耗统计。
- 点击「查看全部」跳转至「积分管理 > 积分明细 > 消耗明细」。

### 4.2 成员消耗

- 展示成员名称、成员标签、统计范围、消耗总积分、消耗总次数。
- 原型示例：`张美丽`、`成员`、`最近24小时`、`消耗总积分 200`、`消耗总次数 50`。
- 提供「查看消耗明细」和「我知道了」操作。

## 5. 消耗趋势

消耗趋势为 T+1 数据，默认统计周期为过去 7 天。

### 5.1 时间范围及统计粒度

- 预置周期：过去 7 天、过去 30 天、上周、上月，默认选中过去 7 天。
- 日期选择：展示当前选择的日期范围；点击可展开日历选择日期。
- 日期边界：最晚可选至昨日，最早可选至积分上线时间，最长可选择 90 天。
- 统计粒度：天、周、月，默认按天。
- 当前趋势图、榜单和导出均使用同一时间范围及统计粒度。

### 5.2 消耗积分趋势

按时间范围及统计粒度展示周期内：

- 总消耗积分趋势；
- 功能消耗积分数趋势；
- 到期失效积分数趋势。

图表使用总消耗柱状图、功能消耗折线和到期失效折线。hover 对应点显示：

```text
2026年2月3日消耗
总消耗积分：3200，功能消耗xxx，到期失效yyy
消耗最多的成员：张三，共消耗300积分，占当日比xx%
消耗最多的功能：无限画布，共消耗1000积分，占当日比bb%
```

### 5.3 消耗成员趋势

按时间范围及统计粒度展示周期内消耗成员趋势图。hover 对应点显示：

```text
2026年2月3日消耗
总消耗成员：32，共消耗积分1000
消耗最多的成员：张三，共消耗300积分，占当日比xx%
消耗最多的功能：无限画布，共消耗1000积分
```

### 5.4 消耗功能趋势

按时间范围及统计粒度展示周期内消耗功能趋势图。hover 对应点显示：

```text
2026年2月3日消耗
总消耗功能：2，共消耗积分1000
消耗最多的功能：无限画布，共消耗300积分，占当日比xx%
消耗最多的成员：张三，共消耗1000积分
```

### 5.5 导出

趋势模块右侧提供「导出」。导出仅包含当前趋势筛选条件下的功能数据；「需求说明」正文、需求描述和重点批注均不进入导出数据。

## 6. 消耗榜单

消耗榜单为 T+1 数据，时间范围与上方选择的时间范围保持一致。

### 6.1 成员消耗榜单

- 按当前时间范围及统计粒度内的消耗量从高到低展示 Top 10 成员。
- 展示信息：成员名称、消耗占比、消耗积分数。
- 消耗占比：周期内 A 成员的消耗积分数 / 所有成员的消耗积分数。

### 6.2 功能消耗榜单

- 按当前时间范围及统计粒度内的消耗量从高到低展示 Top 10 功能。
- 展示信息：功能名称、消耗占比、消耗积分数。
- 消耗占比：周期内 A 功能的消耗积分数 / 所有功能的消耗积分数。

## 7. 权限、会员版本与数据口径

1. 积分统计与使用统计的权限和会员版本限制保持一致。
2. 所有数据限定当前团队，不跨团队聚合；团队切换后重新加载当前团队数据。
3. 积分概览和今日使用为实时数据，趋势和榜单为 T+1 数据。
4. 趋势、榜单、指标和今日使用必须使用相同的团队、时区和积分账本口径。
5. 积分按整数展示；百分比按规则保留两位小数。
6. 原型示例数据只用于页面验证，不能作为正式财务或积分结算数据。

## 8. 页面状态

| 状态 | 页面表现 | 操作 |
| --- | --- | --- |
| 加载中 | 指标、今日使用、趋势和榜单显示加载中 | 等待请求完成 |
| 空数据 | 对应模块显示「暂无积分消耗数据」 | 调整时间范围或统计维度 |
| 加载失败 | 显示「积分统计加载失败，请重试」 | 点击重试 |
| 无权限 | 显示无权限说明，不展示其他团队数据 | 返回账户概览或联系管理员 |
| 导出中 | 导出按钮进入处理中，避免重复提交 | 等待完成 |
| 导出失败 | 显示导出失败提示，不生成空文件 | 重试导出 |

## 9. 验收标准

- [ ] 积分统计与使用统计在团队管理侧边栏同级，使用统计暂未放置内容。
- [ ] 页面包含积分概览、今日使用、消耗趋势、消耗榜单四部分。
- [ ] 积分概览展示剩余积分、本月已消耗、今日已消耗，并符合升级会员/增购显示规则。
- [ ] 本月和今日变化率支持 hover 详情，并符合计算公式、颜色和 0 值展示规则。
- [ ] 今日使用展示最近 24 小时消耗明细，最多 5000 条，并提供查看全部入口。
- [ ] 成员消耗展示成员标签、最近24小时、总积分、总次数和两个操作。
- [ ] 趋势支持四种预置周期、自定义日期、天/周/月粒度和三个趋势维度。
- [ ] 趋势 hover 文案包含对应维度要求的分析信息，并区分总消耗、功能消耗、到期失效。
- [ ] 成员榜单和功能榜单均展示 Top 10、名称、消耗占比和消耗积分。
- [ ] 导出只包含功能数据，不包含需求说明、需求描述和截图批注。
- [ ] 页面右上角「需求说明」按钮打开独立需求文档。
